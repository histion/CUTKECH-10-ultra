酷态科10号Ultra  CUKTECH AD1204U
===================================

这是什么
--------
通过蓝牙（小米 MiOT 协议）连接充电器，做三件事：

1. 监视：四个口的电压/电流/功率、协商到的 PD 档位、功率仪表盘 + 实时曲线。
2. 控制：直接从电脑上开关四个口、逐口开关快充协议、切场景模式、
   改息屏时间/语言/屏幕方向锁等。每次写入设备都会回读确认，
   界面上的开关状态就是设备真实状态。
3. 用电量统计：对瞬时功率做时间积分（米家 App 也是这个思路），按天分桶存盘，
   重启不丢。有今日/累计/本次会话、近 7 天柱状图、每口分解和充电会话列表。

界面风格一键切换
----------------
界面右上角的「鸿蒙 UI / 经典 UI」按钮可以在两套外观之间一键切换：

  · 经典：原来的深色科技风（默认）。
  · 鸿蒙：按 HarmonyOS 设计规范做的浅色界面 —— 系统蓝 #007DFF、胶囊按钮、
    8/12/16 圆角、轻阴影；按钮里用的是 OpenHarmony 官方设计图标包
    （OpenHarmony_Icons.zip，许可 CC-BY-4.0）。

只换外观：布局、尺寸、功能、数据一律不动（已用脚本逐条比对过布局属性，零差异）。
开关状态记在 config.json 的 uiTheme 里，下次启动自动沿用；安卓版与桌面版共用
同一份前端，所以两端的切换方式完全一致。

适用型号：酷态科 10 号 Ultra，型号 AD1204U（蓝牙名形如 njcuk.fitting.ad1204）。

本仓库是源码，最终交付物是从源码编译出的单文件 exe
（dist_py\cuktech 10 ultra.exe）。下面先讲怎么编译，再讲怎么用。


从源码编译（产出单文件 exe）
--------------------------
前置：本机已安装 **Python 3.13** 且 `python` 在 PATH 里（不需要 Node.js）。

方法一（推荐，一键）：
  双击 `build_py\重新打包exe(Python版).bat`。
  首次运行会自动建一个虚拟环境（build_py\.venv）并安装依赖，之后调用
  PyInstaller 打包，产物落在 `dist_py\cuktech 10 ultra.exe`。

方法二（手动）：
  cd build_py
  python -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements-build.txt
  .venv\Scripts\python.exe build.py
  产物同样是 dist_py\cuktech 10 ultra.exe（约 17 MB，GUI 子系统，双击无控制台）。

依赖版本锁定在 build_py\requirements-build.txt（PyInstaller / bleak / aiohttp /
cryptography / cffi / winrt-Windows.Devices.Bluetooth），与已发布版本一致。


怎么用（运行编译出的 exe）
------------------------
1. 双击 `dist_py\cuktech 10 ultra.exe`。
   首次会打开应用窗口（浏览器 app 模式：无地址栏、无标签页，观感等同原生程序）。
   窗口用系统自带的 Edge 打开，并沿用你自己的 Edge 档案（登录态、扩展、设置都在），
   与平时用的 Edge 是同一个，不是另起的全新浏览器。
2. 若提示「尚未登录小米云」，点右上角「登录小米云」，用手机米家 App
   扫描二维码并确认授权。只需一次，之后不会再要求。
3. 把设备插到充电头的 C1 / C2 / C3 / USB-A 口上，曲线会跟着实时变化。

关于控制功能
------------
* 端口开关、场景模式（AI/数码生态/单口/均衡）、息屏时间、屏幕语言、
  USB-A 小电流、空闲自动熄屏、锁定屏幕方向 —— 这些都实测可写、可回读。
* 「恢复常用默认」会把四个口全开、场景切回 AI，分两条逐一下发。

协议开关（逐口启用/关闭快充协议）
--------------------------------
对应设备属性 2.21（PIID 0x15，32 位掩码）。面板上共 10 个开关：

  C1：PD / PPS / UFCS        C2：PD / PPS / UFCS
  C3：UFCS / SCP             USB-A：UFCS / SCP

位定义（2026-09-22 在这台真机上逐位验证过：关掉 USB-A 的 UFCS 后
回读 0x02030F0F、再打开回读 0x03030F0F）：

  C1   bit0=PD  bit1=PPS  bit2=UFCS   （bit3 是固定为 1 的保留位）
  C2   bit8=PD  bit9=PPS  bit10=UFCS  （bit11 是固定为 1 的保留位）
  C3   bit16=UFCS  bit17=SCP
  A    bit24=UFCS  bit25=SCP

  掩码 = aFlags<<24 | c3Flags<<16 | c2Flags<<8 | c1Flags
  出厂默认 0x03030F0F，即四口协议全开。

面板上的「全部开启 / 全部关闭」只改这 10 个开关位，不会碰两个保留位。
关掉某个协议后，该口和设备重新协商时就不会再用这个协议（比如关掉 PD，
手机插上就只能跑 5V 常规充电或走剩下的协议）。
点完开关设备会主动推一帧 2.21 的新值过来，所以界面刷新很快。

关于「定时关闭」
----------------
**本机固件没有这个功能**。官方 MIoT 规格表把它记在 2.9-2.12
（每口一个 u16，0-1440 分钟），但 2026-09-22 用 --probe 的请求形状矩阵实测：
把 2.7 换成 2.8 的「15 项」请求能正常应答，换成 2.9 / 2.10 / 2.11 / 2.12
则整批被静默丢弃 —— 说明这四个属性没有下发到这台固件的属性表里，
米家 App 里也没有对应开关。所以界面里做不了定时关闭。

高级区（原始属性 / 扩展读取）
-----------------------------
* 协议控制字 2.7、端口关闭设置 2.8：语义未查清，只在明确知道要写什么时
  手动填 16 进制原始数值。2.8 出厂值 0x00。
* 协议开关掩码 2.21：就是上面的协议开关面板，留这个输入框是为了整块复原。
* 「读取扩展属性 2.8」：这台设备只认**正好 15 项**的请求，2.8 不在常态轮询的
  15 项里，所以用一次「把 2.7 换成 2.8」的替换形状单独问它。
* 「恢复出厂设置」：调用设备自带的 MIOT action #1，会把端口开关、场景、
  息屏、协议开关全部恢复出厂值，不可撤销，需要二次确认。
* 「扫描隐藏属性 / 温度」：见下面「它读不到什么」。

用电量统计怎么算的
------------------
充电头本身没有"累计电量"属性，只有瞬时 V/A/W。本应用按梯形法对功率做时间
积分：两次采样间隔超过 60 秒的那一段整段丢弃（宁可少算也不瞎算）。结果按天
存到 data\energy.json，同时每口分开记。想清零就删掉这个文件。

它读不到什么（重要）
--------------------
1. 线缆 eMarker：USB-PD 协议里没有任何命令能让外部查询"源刚才从线缆读到了
   什么"，蓝牙属性表里也不存在。所以本应用读不到线缆身份。
   替代用法：在同一条 20V 合约下换线，对比「协商上限」数字的变化来间接判断。
2. 温度：充电头屏幕能显示温度（内部有 NTC），但 2026-09-22 实测确认温度
   **没有任何对外出口**——
   - 官方 MIoT 规格表里（同一个 device urn，米家产品 id 0x660E）共 21 个属性，
     逐项核过，没有温度项；
   - 第三方项目 zuyan9/ha-cuk-ble 的逆向文档「Temperature exposure check」
     在 root 平板上抓了 191 行 BLE 流量，同样没有任何温度字段；
   - 这台设备只回答"那 15 个属性的完整请求"，多加一个或少加一个属性，整个
     请求都被静默丢弃，所以连"枚举未知属性"都做不到；
   - 蓝牙 GATT 全表只有 3 个服务，厂商服务 0xAF00 下只有一个只写特征和一个
     只通知特征，订阅 10 秒收不到任何数据。
   想拿温度只能读它的屏幕（摄像头/OCR），或者拆机飞线 SWD。
   界面「控制充电头 - 高级 - 扫描隐藏属性 / 温度」可以随时重跑这套实测，
   固件升级后如果有新属性会在这里冒出来。

任务栏功率图标
--------------
启动后在屏幕右下角通知区会有一个功率图标：

* 图标里实时显示当前总功率（超过 1000 W 显示 1.2k 这样的缩写）。
* 悬停提示：总功率 + C1/C2/C3/USB-A 四个口的分口功率。
* 右键菜单：打开窗口 / 切换显示模式 / 退出。
* 显示模式两种（网页「托盘显示」下拉或右键菜单都可切换，即时生效）：
  - 仅总功率：图标只显示总瓦数（默认）。
  - 全部功率（轮流）：16 像素的小图标放不下 5 个数字，改为每秒轮流显示
    总功率 → C1 → C2 → C3 → USB-A，每个口有自己的颜色（青/绿/黄/紫）。
* 去掉「任务栏功率图标」勾选即整体关闭；图标连续 6 秒联系不上服务时
  会自动消失，不会留孤儿图标。
* 「托盘显示」第三种模式「一行面板（四口+总）」：把一行功率文字直接嵌进
   任务栏（时钟左边、垂直居中），背景完全透明，看起来像任务栏自带的部件；
  文字按口配色（总=白 C1=青 C2=绿 C3=黄 A=紫），双击面板打开主窗口，
  右键面板与右键托盘图标菜单相同。嵌不进任务栏的机器上会退回悬浮小条。
* 面板里每个数字 1 秒刷新一次；连接断开时显示「连接中…」。


注意
----
* 蓝牙同时只允许一个中心端连接。如果米家 App 正连着这个充电头，请先在
  米家 App 里断开它，否则本应用连不上。
* 充电头必须插着市电。
* 采样间隔可在「协议协商」卡片里调整，默认 1.5 秒。历史保留最近 1 小时。
* 后台常驻规则：只要「任务栏功率图标」开着（默认开），窗口最小化甚至关闭后
  服务也会一直留在后台（图标每秒轮询即保活），任务栏图标/面板照常更新；
  双击 exe 或右键托盘图标「打开窗口」都能把窗口叫回来，不会起第二个服务。
  关掉托盘图标后，2 分钟无请求服务才自动退出，不留幽灵进程。

文件说明
--------
pyapp\              后端服务（HTTP API + 管理采集器进程 + 用电量账本 + A 口自动化）
collector.py        蓝牙采集器（由 pyapp 自动启动；--sweep 扫描属性表，--probe 跑请求形状矩阵）
login.py            小米云扫码登录
vendor\             第三方协议库（MIT 许可，取自 zuyan9/ha-cuk-ble）
web\index.html      界面（单文件，无任何外部依赖）
app.ico             exe 图标
tray.ps1            任务栏功率图标（由 pyapp 自动启动，无需手动运行）
build_py\           打包链路（build.py + cuktech10ultra.spec + requirements-build.txt + 一键 bat）
docs\system_design.md  架构与设计文档（含接口对齐、autoA 规格、迁移兼容）
data\               运行时数据（**不入库**）：token、电量账本、历史、日志、二维码

数据目录：默认在 %LOCALAPPDATA%\cuktech10ultra\data；
可通过环境变量 CUKTECH_HOME 覆盖（测试隔离用）。data\ 已在 .gitignore 排除，
不会随仓库上传。

排障
----
* 编译失败、报找不到 python：先把 Python 3.13 装好并加入 PATH，再双击
  build_py\重新打包exe(Python版).bat。
* 窗口没出现、或服务起不来：在命令行直接跑 `dist_py\cuktech 10 ultra.exe`
  （或设 CUKTECH_NO_WINDOW=1 看控制台日志），报错会直接显示。
* 一直停在「搜索中」：确认充电头已通电、米家 App 已断开它、离电脑近一些。
* 控制按钮点了没反应：多半是蓝牙还没连上，或者米家 App 占着连接；
  看「控制充电头」卡片右上角的提示文字。
* 协议开关点了没变化：等 1-2 秒（设备会主动推新值），或看卡片右上角提示。
* 想清空历史：删掉 data\history.jsonl；想清空电量：删掉 data\energy.json。
